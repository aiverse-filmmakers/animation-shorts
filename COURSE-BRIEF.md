# AI Animation Shorts

## Intent

Build a beginner-friendly standalone course website that teaches people to make original AI-assisted animated shorts.

## Teaching order

1. Story before tools.
2. Character, world and visual rules before generation.
3. Images and animation as shots that serve a story beat.
4. Sound, pacing and assembly only after usable shots exist.
5. Original finished short, with an honest delivery process.

## Audience

A complete beginner who wants to create a short animation, not merely generate disconnected AI clips.

## Non-goals

1. Copying award-winning films, protected characters, scripts, styles or dialogue.
2. Treating prompt generation as storytelling.
3. Teaching camera theory or professional animation software as prerequisites.
4. Publishing untested AI routes as tested.

## Required course standards

1. Award-winning animation research informs transferable mechanisms only.
2. Every lesson is practical, plain-language and complete.
3. Workflow evidence must prove the exact lesson task.
4. Static visuals never prove a video or animation workflow.
5. Website navigation must show every lesson, auto-open the current module and visibly select the active lesson.
6. Mobile must be fully usable without horizontal overflow.
7. Any future Skool transfer uses one lesson per vertical Markdown page, without cards, tables or timelines.
