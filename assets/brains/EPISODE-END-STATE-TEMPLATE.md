# Episode End State Template

Use this after each completed episode. It records what is true now so the next episode resumes from the correct state.

```text
SERIES TITLE:
EPISODE ID:
EPISODE TITLE:
EPISODE STATUS: FINAL / TO VERIFY
FINAL EPISODE FILE:

EPISODE SUMMARY:

CHARACTER STATE AFTER THIS EPISODE
CHAR-01:
PHYSICAL STATE:
EMOTIONAL STATE:
CURRENT WANT:
WHAT THEY NOW KNOW:
WHAT THEY STILL DO NOT KNOW:
RELATIONSHIP CHANGES:
ITEMS CARRIED / LOST / BROKEN / GAINED:
LOCATION AT END:

[repeat for affected recurring characters]

WORLD / LOCATION CHANGES:
PROP / OBJECT CHANGES:
NEW PERMANENT CANON CREATED:
TEMPORARY CONDITIONS THAT SHOULD NOT ENTER PERMANENT CANON:

RESOLVED THREADS:
OPEN THREADS:
SETUPS / PAYOFFS STILL OWED:

NEXT EPISODE START STATE:
CONTRADICTIONS TO RESOLVE:
```

## Save rule

Use episode-safe filenames such as `E01-END-STATE.md`, `E02-END-STATE.md`. Keep every released episode state in the archive, and attach the latest state when continuing the series.
